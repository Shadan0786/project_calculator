# Project Calculator

A web-based calculator application built with HTML and JavaScript.

## Project Overview

This repository contains a calculator application with a responsive user interface and full calculation capabilities.

## Technology Stack

- **HTML** (71.1%) - Structure and layout
- **JavaScript** (28.9%) - Interactive functionality and calculations

## Features

- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clean and intuitive user interface
- Real-time calculation display
- Error handling for invalid inputs

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Shadan0786/project_calculator.git
   ```

2. Navigate to the project directory:
   ```bash
   cd project_calculator
   ```

3. Open `index.html` in your web browser to use the calculator.

## Usage

Simply enter numbers and select operations using the calculator interface. The result will be displayed instantly.
